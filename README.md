# squirrelai-skills
Skill library for Squirrel AI sales coaching system.

## Structure
- `drafts/`      — Candidate skills (DeepSeek generated, pending review)
- `approved/`    — Production skills (Source of Truth for RAGFlow)
- `deprecated/`  — Retired skills (history preserved)
- `schemas/`     — YAML/JSON metadata schema for skill validation
- `scripts/`     — Tooling: lint, sync to RAGFlow, Feishu webhook
